模組分工與隔離藍圖

目標：每個功能只負責自己的工作，任何改動都盡量不影響其他區塊。

責任分區

每一區都有允許依賴與禁止跨界事項。

公開 Facade

UI、分頁與 Feature 只呼叫這些公開介面，不碰內部私有函式。

模組溝通事件

跨系統通知使用 Event Bus，降低互相 import 的依賴。

安全搬移順序

不一次重寫。每一階段都保持舊版可運作與可回退。

隔離規則

新功能從 V5.1.3.28 起不得再直接塞進 11,000 行主 Runtime；先接公開介面。舊功能則逐步搬移，不一次大改。
